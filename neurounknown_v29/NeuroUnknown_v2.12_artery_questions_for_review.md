Rules already applied to the wrong answers: never a parent or branch of the correct artery, never the same arterial family, and (for clinical notes) never an artery whose card shares the key deficit (weakness, visual loss, aphasia, cerebellar signs, memory, third-nerve palsy, haemorrhage).
